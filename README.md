# Simple Archiver

Консольный архиватор файлов на Go. Сжимает данные алгоритмом RLE (Run-Length Encoding), а работать с ним можно через интерактивное меню в терминале на [Bubble Tea](https://github.com/charmbracelet/bubbletea).

## Возможности

- Сжатие любого файла в архив `.sarch`
- Распаковка архива с восстановлением исходного имени файла
- Потоковая обработка блоками по 8 КБ, поэтому большие файлы не загружаются в память целиком
- Интерактивное меню: навигация стрелками, ввод пути, вывод ошибок

## Требования

- Go 1.26 или новее

## Сборка и запуск

```bash
git clone https://github.com/egorka-hub/simple-archiver.git
cd simple-archiver
go build -o archiver .
./archiver
```

Или без сборки бинарника:

```bash
go run .
```

## Использование

После запуска откроется главное меню:

```
=== Простой архиватор ===

> Сжать файл
  Распаковать файл
  Выход

Используйте стрелки для навигации и enter для выбора
Нажмите q для выхода
```

| Клавиша | Действие |
|---|---|
| `↑` / `k`, `↓` / `j` | Перемещение по меню |
| `Enter` | Выбрать пункт / подтвердить путь |
| `Esc` | Вернуться из ввода пути в меню |
| `q` | Выход (в меню) |
| `Ctrl+C` | Выход из любого экрана |

### Сжатие

1. Выберите «Сжать файл».
2. Введите путь к файлу, например `test.txt`, и нажмите `Enter`.

```
=== Простой архиватор ===

Введите путь к файлу для сжатия:
test.txt_

Enter для подтверждения, Esc для возврата в меню
```

Рядом с исходным файлом появится архив `test.txt.sarch`, а программа вернётся в меню.

### Распаковка

1. Выберите «Распаковать файл».
2. Введите путь к архиву, например `test.txt.sarch`, и нажмите `Enter`.

Файл восстанавливается под исходным именем (`test.txt`) в той же папке, где лежит архив. Если файл с таким именем уже есть, он будет перезаписан.

### Ошибки

Если файл не найден или архив повреждён, ошибка выводится прямо на экране ввода. Путь можно исправить или вернуться в меню по `Esc`:

```
Введите путь к файлу для сжатия:
nonexistent.txt_

Ошибка: failed to open input file: open nonexistent.txt: no such file or directory
```

## Как устроено сжатие

### RLE

Данные кодируются группами. Каждая группа начинается с управляющего байта:

| Старший бит | Младшие 7 бит | Что следует дальше |
|---|---|---|
| `1` | длина серии (4–127) | один байт, который повторяется указанное число раз |
| `0` | длина группы (1–127) | столько же байт без изменений |

Пример: `AAAABBBCCCCCC` превращается в `0x84 'A'`, `0x03 'B' 'B' 'B'`, `0x86 'C'`.

Серии короче 4 байт записываются как есть: их сжатие не дало бы выигрыша.

### Формат файла `.sarch`

```
[1 байт: длина имени][имя исходного файла]
[2 байта: размер блока, big-endian][сжатый блок]
[2 байта: размер блока, big-endian][сжатый блок]
...
```

Имя файла хранится в архиве, поэтому распаковка восстанавливает его без участия пользователя.

## Структура проекта

```
simple-archiver/
├── main.go      # весь код: RLE-сжатие, работа с файлами, TUI на Bubble Tea
├── test.txt     # пример файла для проверки сжатия
├── go.mod       # модуль и зависимости
├── go.sum
└── README.md
```

Код в `main.go` разделён на три части:

- **`SimpleArchiver`**: алгоритм RLE (`compress`, `decompress`) и работа с файлами (`CompressFile`, `DecompressFile`)
- **`model`**: состояние интерфейса и методы Bubble Tea (`Init`, `Update`, `View`)
- **`main`**: запуск программы через `tea.NewProgram`

Автоматических тестов пока нет.
